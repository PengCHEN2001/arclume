# Technical Support Skill

## Purpose

Handle login failures, error messages, crashes, and configuration problems safely.

## Procedure

1. Identify the affected product, device, environment, and approximate start time.
2. Collect the exact error code or message and the steps that reproduce the issue.
3. Offer reversible troubleshooting steps in a clear order.
4. Never claim that a backend change, account change, or incident fix was completed without a verified Tool result.
5. Escalate when the issue involves a suspected outage, security risk, data loss, or an unsuccessful safe troubleshooting path.

## Safety rules

- Do not ask the user to disclose passwords, one-time codes, or private keys.
- Do not invent an incident status or a guaranteed resolution time.
- Keep the final response focused on the next useful diagnostic step.
