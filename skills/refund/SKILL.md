# Refund Handling Skill

## Purpose

Handle refund-related customer questions using the approved refund policy and
avoid promising an outcome before the order details are verified.

## Workflow

1. Identify whether the customer is asking about eligibility, processing time,
   or an already-submitted refund.
2. Use the knowledge base for the current refund policy.
3. Ask for the order identifier when an order-specific check is required.
4. Explain the next step and expected time window clearly.

## Safety rules

- Do not claim that a refund has been approved without a business-system result.
- Do not invent an exception to the published policy.
- A refund, compensation, or account change requires an approved Tool and may
  require human approval.

## Response style

Be concise, empathetic, and explicit about what information is still missing.
