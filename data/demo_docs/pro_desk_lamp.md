# Arclume Pro Desk Lamp (AL-P200)

## Product overview

The Pro is an adjustable desk lamp with touch controls and optional control
through the Arclume mobile app. Model AL-P200 supports brightness changes,
white-light color settings, and schedules in the app. It can still be switched
on and adjusted with its touch controls when the app is unavailable.

## Network requirements

The Pro connects to a 2.4 GHz Wi-Fi network for app features. It does not join
a 5 GHz-only network. The phone and lamp should be on the same 2.4 GHz network
during initial pairing. This network requirement applies to the Pro, not the
Mini model AL-M100, which has no app connectivity.
